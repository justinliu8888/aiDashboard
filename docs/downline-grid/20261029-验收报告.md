## 5. 已知缺口（**不与通过项混写**）

1. **`exclusions`（筛选与排除项）本期未实现** —— **代码层事实**：方案里的 `exclusions` 在草稿转换里**没有落点**，
   全仓找不到把它带进草稿的路径。需求稿 §2.5 要求「指标和范围：筛选及排除项与方案一致」，
   **「筛选与排除项与方案一致」这一条尚未满足。**
   （本轮真实模型给的方案**本身就没有排除项**——展开的「需求」区显示「排除项：无」，见 `wb42-02` 截图——
   所以这个缺口在本次端到端里**无法被观测到**，它是靠代码核对得出的，不能声称「已验证通过」。）
2. **`renderChart` 在草稿路径生产上不可达** —— `renderChart` 已导出给草稿路径复用（`workbench_plan.js:709`），
   但草稿区域的 `region.data` 是**执行绑定描述符**（`{inputs, pipeline, outputs}`），**不带 `xLabels` / `yValues`**，
   `renderRealChart`（`workbench.js:2225`）必然返回 null → 永远回落空壳卡片。
   **本轮实测佐证**：试运行后 `#preview-root svg` 数量 = **0**（真正带数据点的预览走 ECharts 那条路）。
   该渲染器按需求稿 §3.3「严禁删除折线图 SVG 渲染」保留，**回归覆盖由单测 T9 守住**；#45 已把注释改成事实描述。
3. **`workbench.js` 的面板切换 / 折叠落点 / `hasPlan` 判据没有前端单测覆盖** —— `renderPlanModule()`
   （`workbench.js:162-192`）里「草稿阶段不清空方案面板」这条判据只靠**交互冒烟**保证。
   本轮 A8/A9/A10 的 `assertVisible` / `assertAttr` / 真实鼠标点击覆盖了行为，但**没有单测**兜底。
4. **预览阶段的渲染器与草稿阶段不是同一套** —— 试运行后 `#preview-root` 里的区域卡片**不带 `data-region-id`**，

   本轮 A20/A21 的断言已按**预览阶段的真实 DOM** 写。这是**既有行为**，不在本轮改动范围内，
